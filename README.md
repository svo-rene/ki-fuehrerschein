# KI-Führerschein – Gymnasium Dresden-Pieschen (Entwurf)

Erster Stand nach dem pädagogischen Tag am 19.11.2026. Entwurf zur Diskussion, noch kein offizielles Angebot der Schule.

Schulweiter KI-Führerschein für die Klassen 5 bis 12 als statische Webseite (`index.html`, Inhalte in `daten.js`),
ohne Server und ohne externe Bibliotheken. Der Fortschritt wird nur im Browser gespeichert.

Vier Führerscheinklassen (5/6, 7/8, 9/10, 11/12), jeweils mit Fahrstunden, Übungsplatz, Theorieprüfung und Praxisprüfung,
dazu ein druckbarer Führerschein und eine Zusammenfassung zum Speichern als PDF.
